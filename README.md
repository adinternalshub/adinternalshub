### 🔎 What I work on

- **Active Directory internals** — replication, FSMO/RID, DFSR, Group Policy, the directory's on-the-wire behaviour
- **Protocols & security** — Kerberos, LDAP, AD CS / PKI, security descriptors and delegation
- **Threat & patch analysis** — breaking down Patch Tuesday and the AD security fixes Microsoft ships
- **Tooling** — focused **PowerShell** and **C# / .NET** utilities that make AD operations measurable and safe

### 🛠️ Featured project

**[ADACLSizeAudit](https://github.com/adinternalshub/ADACLSizeAudit)** — proactively audits Active Directory security-descriptor (ACL) sizes against the 64 KB limit the directory enforces. Reads over LDAP only, writes nothing, and explains *why* each descriptor is large so objects can be fixed before writes to them start failing. A single self-contained .NET executable with an HTML dashboard, CSV export and JSON baseline tracking.
